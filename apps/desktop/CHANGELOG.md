# Changelog — @md-business/desktop

このアプリの変更履歴。バージョンは [Semantic Versioning](https://semver.org/lang/ja/) に従う。

英語版は [CHANGELOG.en.md](./CHANGELOG.en.md)。版を足すときは両方に足す（片方だけだとテストで落ちる）。

## 0.7.0

### 追加

- **JSON と XML を、木構造で開けるようになった**。設定ファイルや取り込んだデータの中身を、別のツールへ移さずに確かめられる。1 行に詰まった JSON でも、折りたたみながら辿れば構造が見える。**書き換えはできない**（読むだけ）。これらは Markdown と違って正本にしていないので、アプリから編集できるようにすると、どちらが本物か分からなくなるため。
  - 深すぎる入れ子や、外部を参照する宣言（DTD）を含む XML は、読まずに理由を添えて断る。開いただけで意図しない読み込みが起きないようにするため。
  - AI からも読める。節を指すと、その部分だけが返る。丸ごと返すとファイルが大きいほど 1 回の応答が膨らむので、既定は 2 世代までで切り、切った先には「あと何個ぶら下がっているか」を添える。黙って縮めると、子が少ないのか無いのかが区別できなくなる。
- **検証シートのセルから、別の箇所や別のファイルへ飛べるようになった**。手順に出てくる設計書の見出しや、前提になる別のシートを、セルに書いておけばその場から開ける。関連する資料を探し直す手間が要らない。同じフォルダの中を指す書き方なので、フォルダごと誰かに渡しても切れない。
- **値がほかの列から決まる列を、計算列として宣言できるようになった**。同じ内容を人が二度書かなくてよくなり、元の列を直せば追随する。計算列は手でも AI からも書き換えられない（書き込もうとすると、どの列が計算列かを添えて断る）。書ける場所と書けない場所が、シートを見ただけで分かる。
- **どこで時間を使っているかを、アプリの中で測れるようにした**（診断パネル）。動きが重いと感じたときに、体感の報告ではなく数字で場所を示せる。

### 変更

- **選択肢のあるセルを、1 クリックで候補ごと開くようにした**。これまでは、セルを選ぶ操作と候補を出す操作で 2 手かかっていた。結果の欄のように選ぶだけの列を何十行も埋める場面で、手数が半分になる。
- **更新のお知らせが、最新の状態でも直近 3 件の内容を出すようになった**。これまで最新のときは何も出ず、「自分が今どこまでのものを使っているか」を確かめる手段が画面の中に無かった。それ以前の分は「もっと見る」からブラウザで一覧を開ける。
- **内蔵の MCP サーバーを、待ち受けに入らずに確かめられるようにした**（`--version` / `--health`）。設定が正しいかどうかを、AI 側から繋ぐ前に切り分けられる。これまでは繋いでみるまで、設定が悪いのかサーバーが動いていないのか分からなかった。
- 見積書・領収書のひな形で、番号の項目名が請求書のままだったのを、それぞれの様式に合った名前に直した。

### 修正

- **検証シートの編集が、行数が増えるほど重くなる問題を直した**。1 文字打つたびに表全体を作り直していたため、行数に比例して反応が遅れていた。見えている範囲だけを描くようにして、行数が増えても打鍵の重さが変わらないようにした。先に測ってから直している（上の診断パネルはそのために作ったもの）。
- 依存ライブラリを脆弱性修正版へ更新した。

## 0.6.0

### 追加

- **検証シートを、列が入った状態で新規作成できるようになった**。これまでは白紙から列名を打ち込むところから始める必要があり、その数分が新しいシートを作るたびに丸ごと重複していた。左側の一覧の右上にある ＋ か、フォルダの右クリックから「試験ケース」「観点表」のどちらかを選ぶと、列と色分けが入った状態で作られ、そのままグリッドで開く。
- **同じ値を下の行へまとめて配れるようになった**（Ctrl+D）。結果・実施日・担当のように、何十行も同じ値が続く欄を 1 操作で埋められる。範囲を選んで押すと先頭行の値が下へ配られ、セルを 1 つだけ選んで押すと真上の値を引く。
- **行を控えにできるようになった**。書き直した元の文言を、消していいか毎回悩まずに残しておくための置き場所。控えにした行は表から外れるが、ファイルには残る。「控え 3 行を表示」のように件数が常に出るので、外したこと自体を忘れない。表計算ソフトの非表示行にあたる。
- **見積書と領収書を、請求書と同じ書式で書けるようになった**。`種別` を書き分けるだけで、表題・有効期限・但し書きが切り替わる。請求書のために作った書式をそのまま使えるので、様式ごとに別のひな形を持たなくてよい。
- **内蔵の MCP サーバーを、手元ですぐ使い始められるようになった**。接続設定を開いているフォルダへ書き出せるようにしたので、AI 側の設定ファイルを手で組み立てなくてよい。Node が見つからないときは、どこに入れればよいかを画面に出す。パソコンに Node が入っていても PATH に無い場合は、よくある場所を探しにいく。

### 変更

- 検証グリッドの行操作の並びで、ボタンの文言を「＋ 末尾に行を追加」「選択行の下に複製」に変えた。どこに行が増えるのかが押す前に分かる。窓を狭めたときに文字が 2 行へ折り返してバーの高さが動いていたのも直した。
- 更新のお知らせに出る変更内容を、記号がそのまま見えていたのを整形して表示するようにした。

### 修正

- **検証シートの行に、見た目の番号とは別の変わらない目印を持たせた**。途中に 1 行挿すと以降の番号が全部ずれるため、行を指して何かを指定する仕組み（色分け・行の高さ・控え）が別の行を指してしまう事故が起きていた。目印は行そのものに付くので、行が動いても付いてきた設定はそのまま残る。
- AI が、開いているフォルダの外にあるファイルへ書き込めないようにする判定を厳しくした。フォルダの中に外を指す近道（シンボリックリンク）が置かれている場合、これまでは名前の見た目だけで判定していたため通り抜ける余地があった。実際に行き着く先を確かめてから書くようにした。
- 依存ライブラリを脆弱性修正版へ更新した。

## 0.5.0

### 追加

- **AI が自分の書き換えを確認して履歴に残せるようになった**。これまでは AI に文書を直してもらったあと、何が変わったかを見て記録に残す部分だけ人がアプリに戻る必要があった。`git_status`（今どのブランチで何が変わっているか）/ `git_diff`（変更の中身）/ `git_commit`（記録に残す）を AI から使えるようにしたので、「直して、差分を見せて、記録して」までを続けて頼める。1 日の作業が、名前のないファイルの山ではなく読める履歴として残る。
  - **リモートへ出す操作（push）は含めない**。外に出す前に人が内容を見る手順は変えない。
  - コミット時のチェック（保存前に走る検査）は迂回しない。AI が記録しても、人がコミットしたときと同じ検査を通る。
- **AI から PDF 出力を頼めるようになった**。`export_pdf` で、開いている文書の印刷ダイアログをアプリ側に出させる。PDF の見た目は画面の表示をそのまま使うため、AI 側で別に組み直した結果とズレることがない。返ってくるのは「ダイアログが開いた」までで、保存したかどうかは人の操作になる。
- **AI が検証シートを自分で見つけられるようになった**。これまで検証シート（タブ区切り形式）を読み書きするツールはファイルの場所を渡す必要があり、人がファイル名を教えない限り AI からは探せなかった。検索結果に検証シートも並ぶようになり、表題（`# タイトル:`）で見分けられる。
- **検証グリッドの列寄せを指定できるようになった**。金額の列を右に寄せる、見出しを左に揃えるといった調整ができる。右クリックメニューの「寄せ」から選ぶと、列名・データ・入力欄・大分類の見出しまでまとめて揃う。指定は検証シートに保存されるので、次に開いたときも保たれる。

### 変更

- ソース管理パネルと差分表示が、日本語のままだったのを表示言語に合わせるようにした。英語 / 中国語 / 韓国語で使っている場合も、コミット欄の説明・変更一覧・差分の見出しがその言語で出る。
- frontmatter を読み取れなかったときの説明を、書いた人向けの言い方に変えた。これまでは英語の技術用語（`bad indentation of a mapping entry`）がそのまま出ていた。何行目の何がおかしいのか（字下げ・タブ・項目名の重複・閉じていない引用符など）を、表示言語に合わせて示す。行番号もファイルの先頭から数えた値に直したので、エディターの行番号とそのまま突き合わせられる。

### 修正

- **検証グリッドで、複数行のセルを含む範囲をコピーしても崩れなくなった**。手順や確認内容を箇条書きで書いたセルをコピーして貼り付けると、そのセル 1 個が 2 行に割れ、以降の列がずれていた。Excel / Google Sheets と同じ方式で、改行やタブを含むセルだけを囲んで受け渡すようにした。表計算ソフトとの行き来もそのまま通る。
- **検証グリッドの範囲選択をマウスでできるようにした**。これまで複数セルの選択は矢印キー（Shift + 矢印）だけで、ドラッグしても反応しなかった。押したセルから通ったセルまでが選択範囲になる。
- AI がファイルを書いている最中にアプリやパソコンが落ちても、元のファイルが壊れなくなった。書き換えは差し替え方式にしたので、途中で止まった場合は書き換え前の内容がそのまま残る。検証シートのように 1 回の書き込みで全体を書き戻す種類のファイルで効く。
- AI が、パソコンで扱いづらい名前のファイル（`CON.md` などの予約された名前、コロンを含む名前）を作れないようにした。とくにコロンを含む名前は、書き込めてもファイル一覧に現れない場所へ内容が入ってしまうため拒否する。
- 内蔵 MCP サーバーの接続トークンの照合を、応答時間から中身を推測されない方式に変えた。
- 依存ライブラリを脆弱性修正版へ更新した。

## 0.4.0

### 追加

- **AI から検証シートを直接編集できるようになった**。これまで内蔵の MCP サーバー経由で扱えるのは Markdown の文書だけで、検証シート（タブ区切り形式）には手が出せなかった。「3 行目の結果を OK にして実施日を入れて」のように依頼すると、その行だけが書き換わる。
  - 列は名前で指定するため、列を並び替えても壊れない。
  - 触っていない行はそのまま残るので、変更履歴の差分に余計な行が出ない。
  - 記入途中の値（選択肢にない結果など）もそのまま書き込み、どのセルが型に合っていないかを併せて返す。書きかけの状態を許容する。
  - 追加したツールは `read_tsv`（読み取り）/ `append_tsv_row`（行追加）/ `update_tsv_row`（行更新）の 3 つ。
- **文書を書き始める前に書式を確認できるようになった**。`get_schema` で、文書の種類ごとの必須項目・型・選択肢をそのまま取得できる。これまでは一度書いてから検証エラーを見て直す往復が必要だった。

### 変更

- MCP 経由で検証シートの行が追加 / 更新されたとき、ファイル一覧とプレビューが自動で追従するようになった（Markdown の作成 / 更新と同じ挙動）。

### 修正

- AI に同じ検証シートへの書き込みをまとめて頼むと、同時に処理された分の行が黙って消えることがあった問題を修正。1 枚のシートへの書き込みは順番に処理する。
- 検証シートの 1 セルと 1 ファイルに大きさの上限を設けた。誤って巨大な値を書き込もうとした場合は、ファイルを書き換えずに理由を返す。
- 深く入れ子になった、あるいは同じ内容を大量に参照する frontmatter を読み込むと、処理が長時間止まることがあった問題を修正。読み込む量に上限を設けて、通常の文書の速度は変えずに打ち切るようにした。
- 日本語キーの変換時の深さ検査が一部の文書種別にしか効いていなかった問題を修正。6 種すべてで同じ上限が働く。

## 0.3.0

### 追加

- **アプリ内蔵の MCP サーバー**。アプリ起動と同時にローカル専用（`127.0.0.1`）の MCP サーバーが立ち上がり、AI クライアントから開いているフォルダの業務文書を読み書きできる。接続先はフォルダを切り替えるたびに追従する。
- **MCP パネル**。右サイドパネルの `MCP` タブに接続先・接続設定のコピー・つなぎ方の手順・ツール実行の操作ログを表示する。表示文言は英語 / 日本語 / 中国語 / 韓国語に対応。
- **接続設定のコピー**。AI クライアントの MCP 設定へそのまま貼れる JSON を 1 押しで写せる。
- **接続先の固定**。ポートと接続トークンを保存し、次に起動しても同じ接続先で立ち上がる。一度貼った設定を書き直さずに使い続けられる。
- **AI の書き込みの自動反映**。MCP 経由で文書が作成 / 更新されると、アプリのファイル一覧とプレビューが自動で追従する。

### 変更

- MCP サーバーが起動できない環境（Node ランタイム未検出など）でも、アプリの他の機能は一切止まらない。パネルに理由だけを表示して動作を続ける。

### 修正

- ステータスバーの MCP 表示が接続状態に関わらず「未接続」のままだった問題を修正。稼働中 / 起動中 / 停止中を色付きで表す。

## 0.2.0

### 追加

- **外部編集のライブ連携**。開いているファイルが他のツールで書き換わると自動で読み込み直す。編集中に外部変更が起きた場合は競合バナーで再読込か自分の変更の維持かを選べる。
- **ヘルプ導線**。上部バーのヘルプから操作マニュアル・バージョン・キーボードショートカット・ライセンスを開ける。
- **UI 多言語対応**（英語 / 日本語 / 中国語 / 韓国語）と、ファイル / 検証グリッド共通の検索。
- **編集体験の改善**。ファイルツリーの右クリックメニュー、TSV グリッドの長文セルの突き抜け表示・undo / redo・オートセーブ、検証グリッドの行の着色・履歴・キー操作、開いていた場所の記憶。

### 修正

- 日本語キーを含む文書が MCP サーバーの検証で必ず invalid になる問題を修正。

## 0.1.0

初回配布リリース。

### 追加

- 6 種の業務文書（invoice / spec / test-spec / db-spec / nosql-db-spec / api-spec）を用途別ビューワーで開き、Markdown を左右 2 画面でライブ編集・PDF 出力する Tauri デスクトップアプリ。
- test-spec の TSV グリッド編集（表計算風の入力ウィジェット + エディターとの round-trip）。
- **アプリ内の自動アップデート**。起動時に新バージョンを自動確認し、ヘルプの「更新を確認」から手動確認もできる。更新は GitHub Releases の署名付き成果物を検証して適用する。

### 配布

- Windows（`.msi` / `.exe`）・macOS（universal `.dmg`）のインストーラを GitHub Releases で配布する。
- コード署名（Windows Authenticode / Apple 公証）は未対応。初回インストール時に発行元不明の警告が出る場合がある。
