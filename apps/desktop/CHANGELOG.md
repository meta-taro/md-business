# Changelog — @md-business/desktop

このアプリの変更履歴。バージョンは [Semantic Versioning](https://semver.org/lang/ja/) に従う。

英語版は [CHANGELOG.en.md](./CHANGELOG.en.md)。版を足すときは両方に足す（片方だけだとテストで落ちる）。

## 0.30.0

### 追加

- **2 つのフォルダを、2 つの窓で並べて開けるようになった**。ファイルメニューの「別の窓を開く」から増やす。窓ごとに開くフォルダは 1 つで、見張り・下見・エージェントの受け口も窓ごとに 1 本ずつ持つ。作りかけのサイトを直しながら、隣の窓で検証シートを埋める、といった使い方ができる。窓ごとに前回のフォルダを覚えるので、次に起ち上げたときも同じ 2 つが並ぶ。**タスクバーと Alt+Tab の項目名は、開いているフォルダの名前になる**（同じ名前が 2 つ並ぶと、どちらがどちらか分からない）。文書名ではなくフォルダ名にしたのは、文書を切り替えるたびに項目名が変わると目で追えなくなるため。同時に開けるのは 8 つまでで、上限に達すると「別の窓を開く」が灰色になる（窓ごとに常駐するものがあるので、際限なく開けると機械が持たない。押しても何も起きない項目にすると、開かなかったのが不具合なのか上限なのか分からない）。

- **同じフォルダを 2 つの窓で開こうとすると断るようにした**。窓ごとに 1 本ずつ持つものが、同じ場所を取り合うため。とくにエージェント向けの接続情報はフォルダに書き出すもので、窓ごとに違う待ち受け先が入る。後から開いた窓が先の窓の分を上書きすると、**先の窓につないだつもりのエージェントが、黙って別の窓のフォルダを触る**。断ると同時に、既にそのフォルダを開いている窓を前に出す（畳まれていると、どこで開いているのか探しに行けない）。親フォルダと子フォルダは指しているところが違うので、そのまま開ける。

## 0.29.0

### 追加

- **フォルダが「サイト」を名乗れるようになった**。`md-business.yml` に `mode: web` と書くと、そのフォルダでは Markdown だけでなく HTML・CSS・JavaScript も一覧に出て、下見が本物のページとして動く。**書いてあるのは宣言であって、実行の許可ではない**。動かすかどうかは、この機械で人が 1 回押して決める。フォルダを配った先へその許可は付いていかない（許可まで一緒に渡ると、受け取った側は中身を見る前に script が動いていることになる）。宣言はアプリから書けるし、取り下げられる。許可も後から取り消せる。**この 2 つは別々に消える**（取り下げても許可は残り、許可を消しても宣言は残る）。片方が他方を消す作りにすると、配布物を直したのに手元だけ動き続ける／手元で断ったのに配布物は宣言したまま、のどちらかが必ず起きる。心当たりの無いフォルダでは許可しないでほしい、と尋ねる画面にも書いてある。

- **下見で script を動かすかを、フォルダごとの同意で決めるようにした**。動かす側にしたページには、読み込んでよい出どころの指定を付ける（宣言に書いていない出どころからは読み込ませない）。**書き出したフォルダにも同じ指定を焼き込む**。手元の下見だけ厳しくしても、出したものが緩ければ守れているのは自分の画面だけになる。

- **外で動いている待ち受けを、同じ面に映せるようになった**。`web:` の下に `devServer: http://localhost:4321` と書くと、下見の面がそこを映す。**アプリはその待ち受けを起動しない**。起動まで持つと、フォルダを開いただけでプロジェクトのコマンドが走ることになり、上の同意が意味を失う。立てるのも止めるのも今までどおり手元の端末で、アプリは映すだけ。宛先はこの機械の中（`localhost`）だけ受け付ける。

- **サイトの部品を、エージェントからも扱えるようになった**（MCP）。書く口・読み返す口・一覧する口と、宣言だけを書く口を足した。書いたものは開いている画面にそのまま届く（開き直さなくても下見が変わる）。アプリの側では**読み取り専用で開く**（直す場所は元のファイルで、写しを直しても戻らない）。

- **本文に ```` ```data ```` の囲みを置くと、別ファイルの表をその場に描くようになった**。`source:` に表の場所を書く。数字を本文へ写すと、表を直したときに本文だけ古いまま残る。指定が通らないときは黙って空にせず、囲みの何行目の何が読めなかったかを出す。

### 修正

- **宣言を書き換えても、一覧が前のままだったのを直した**。
- **サイトの部品を、中身が書き換わっただけのときに組み直さないようにした**。ライブ更新のたびに全部を組み直していた。

## 0.28.0

### 追加

- **Markdown の脚注（`[^1]`）が注釈として読めるようになった**。脚注は本文に肩番号だけを残して、本文を文書の末尾へ畳む。紙ならページを戻れば済むが、画面では**末尾まで目を移した時点で読んでいた場所を見失う**。表や図の途中だと、戻ってきても同じ行を探すところからやり直しになる。肩番号にカーソルを合わせると、その場に本文が出るようにした。末尾の一覧は今までどおり残す（**一覧のほうが正で、その場に出るのは同じ本文の写し**。印刷や読み上げには一覧だけが出る）。読み上げには二度読ませない（肩番号は既に末尾の本文を指しているので、写しまで読ませると同じ文が続けて 2 回読まれる）。**紙では戻る記号（`↩`）を出さない**。画面では一覧から本文へ帰る道になるが、紙の上では押せない記号が番号の隣に並ぶだけで、意味を探させるぶん読みにくくなる。体裁は本文より小さく、上に区切りを引いて、章見出しの装飾は引き継がせない（注釈は章ではない）。

### 修正

- **末尾の注釈の見出しが、日本語の文書にも英語で `Footnotes` と刷られていたのを直した**。脚注の既定の見出しは英語で、しかも「読み上げにだけ残して目には見せない」前提の指定が付いている。その指定に当たるスタイルをこちらは持っていないので、**隠れないまま英語の見出しだけが出ていた**。隠すのではなく、文書の言語の見出しとして出す（注釈 / Notes / 注释 / 주석）。戻る記号の読み上げラベルも同じ言語で出す。目に映るのは記号だけなので気づきにくいが、読み上げるとそこだけ英語が挟まる。

## 0.27.0

### 追加

- **セルに注釈を付けられるようになった**。「なぜこの値なのか」を書き残す場所が `備考` 列しかなかった。`備考` に寄せると**どのセルの話か落ちる**（1 行に理由が 3 つ並ぶと、どれがどの列の話なのかを読む側では決められない）。かといってセルの中へ直接書くと、今度は表として読めなくなる。注釈はその行き場で、**セルに紐づいた本文を表の外に持つ**。画面ではセルの右上に小さな印が出て、ホバーと選択で本文が出る（Ctrl / ⌘ + Alt + M で追加、右クリックから編集と削除）。**印（`#@ mark`）とは別の宣言にしてある**：印は「ここが変わった」で次の版で消えるが、注釈は「なぜこうなのか」で値が変わらない限り残る。混ぜると、印を消す操作で注釈まで消える。同じセルに何件でも付けられ、まとめずに書いた順で並ぶ（別々に消せる必要がある）。**行は行 ID で指す**（行番号だと 1 行挿した時点で別のセルの注釈になる）。紙と PDF では**セルに番号だけ**を出し、本文は文書の末尾へまとめる（紙でセルの中へ展開すると `備考` 列の問題へ戻ってしまう）。番号は**刷るときに上から振る**のでファイルには持たない（1 件挿しただけで以降の全番号が振り直しになり、差分が読めなくなる）。提出様式へも出せるが、**様式に書いたときだけ**（様式の列を決めているのは先方なので、黙って 1 列増えると受け取る側の取り込みが崩れる）。**列名を打ち間違えた注釈も、控えにした行を指す注釈も、黙って消さない**（読み込みで捨てると、注釈があること自体が見えなくなる）。エージェントからは**読めるが書けない**（注釈は人が自分の言葉で残すところで、同じ欄を埋められると、後から読んだ人にはどちらの言い分か分からなくなる）。

## 0.26.0

### 追加

- **見たい行だけを表に残せるようになった**。シートが 200 行を超えると、直したい行まで画面を送って探すことになる。探す（Ctrl+F）は**当たりへ飛ぶだけ**で、当たっていない行は画面に残り続けるので、「`結果` が NG の行を通しで直す」ができない。選んでいるセルと同じ値の行だけにする口と、探した言葉が当たった行だけにする口の 2 つを付けた。押すたびにさらに絞れる。**ファイルには何も書かない**（控えにした行との決定的な違いはここで、絞ったまま保存しても外した行は元の位置に残るし、開き直せば絞り込みは消えている）。**持ち出し（提出様式のコピー）にも影響しない**。見えていない行が黙って提出物から落ちるのがいちばんまずい壊れ方になる。外す行は**押した時点で決めて固定する**（当たり続けている行を毎回数え直すと、`結果` を NG から OK へ直した瞬間にその行が目の前から消える。直している最中の行が消えるのは、どう説明しても事故に見える）。同じ理由で、絞り込み中に足した行は外れない。**絞っている間は番号を振り直さない**（表に出ている行だけで `rowNumber()` を数え直すと、外している行を飛ばした番号がそのままファイルへ焼かれる）。解いた時点で全行そろった状態で数え直す。外している行数は常に画面に出す。出さないと、行が消えたと受け取られる。

## 0.25.0

### 追加

- **提出様式で出した表を、返ってきたあと正本へ戻せるようになった**。前の版で出す口はできたが、戻す口が無かった。先方は提出物の側に結果を書いて返してくるので、それを正本へ移すのは人が目で写す作業になる。**写し漏れは提出物の側にしか出ない**ので、こちらの手元をいくら見ても見つからない。様式にどの列で行を当てるかを書いておけば、返ってきた表を貼り付けから読んで戻せる。**位置では当てない**（提出物は先方の手元で並べ替えられ、行が挿され、いらない行が消される。返ってきた表の「何行目か」は出したときの何行目かと関係が無い）。**行は足さないし消さない**。正本に無いキーは報告して終わりにする（先方が足した行を取り込むと、採番・行 ID・計算列の前提が同時に崩れる）。**変わったセルだけ**を戻す（提出してから返るまでの間にこちらでも正本を直している。全セルを書き戻すと、その直しが黙って古い値へ戻る）。計算列・行 ID 列・様式が同じ列を 2 回出しているときのその列には書かない（最後のものは、片方だけ直された表が返ってきたときにどちらが本当かをこちらでは決められない）。改行を空白に畳む様式は**取り込み自体を断る**（畳んだ改行はもともとの空白と区別が付かないので、取り込めば先方が触っていないセルからも改行が消える）。押すと先に**戻せる件数・当たらなかったキー・書かなかった列**が出て、それを見てから当てる。1 段で書き込むと、キーが 1 つも当たっていないことに気づけない（「0 件変わりました」は「もう全部入っている」とも読める）。当てた後は取り消しで戻せる。

### 修正

- **ブラウザで見るときの合鍵の照合が、合っている文字数で速さの変わる形だったのを直した**。違う文字を見つけた時点で戻る書き方だったので、返るまでの時間を測れば 1 文字ずつ当てられ、総当たりより桁違いに少ない試行で合鍵が割れる。待ち受けているのは手元だけだが、同じ機械で動いている別のものからは叩ける（そこを塞ぐために合鍵を置いている）。最後まで見てから答える形にした。

## 0.24.0

### 追加

- **検証シートを紙の版面で下見して、そのまま PDF・HTML・画像に出せるようになった**。検証シートの本則は TSV で、右ペインは編集用のグリッドとして開く。グリッドは印刷対象の面を持たないので、**開いている間は書き出しが一切押せなかった**。紙が要る場面では同じ内容をもう 1 枚 Markdown で持つことになり、**2 枚あれば必ず片方が古くなる**。古いほうを出しても、出した側は気づけない。グリッドをそのまま印刷はしない（画面に収めるために列幅を詰め、行を仮想化し、入力中のセルを枠で囲うので、写しても読めるものにならない）。代わりに印刷用へ組み直した「下見」へ切り替える。見出し行は 2 ページ目以降にも繰り返し、セル内の改行はそのまま改行として出す。行の色は地色として出すが、**色だけで意味を伝えない**（判定の文字は残す）。**控えにした行と行 ID の列は紙にも出ない**（表に出していないものが紙にだけ現れると、渡した相手には消したはずのものが見える）。横に長いので A4 横を既定にした。下見・PDF・HTML・画像はすべて同じ 1 本の組み立てを通るので、**画面で確かめたものがそのまま出る**。切り替えてもファイルは書き換わらない（下見に入っただけで「編集した」にならない）。

## 0.23.0

### 追加

- **既にあるリポジトリを、開いている空のフォルダへ複製できるようになった**。これまでアプリでできたのは手元のフォルダを新しくリポジトリにすることだけで、**既に置き先にあるものを持ってくる手立てが無かった**。アプリは資格情報を持たないし尋ねない。認証は OS の git 資格情報と SSH に委ねる。そのうえで、資格情報が埋まった URL・暗号化されない `http://`・任意のコマンドを走らせうる scheme は入り口で断る。認証が通らないときは、利用者名やパスワードを尋ねさせずにその場で失敗させる（子プロセスには答える人がいないので、尋ね始めると誰も気づかないまま固まる）。複製先は開いているフォルダそのもので、空でなければ断る。
- **ブランチを作って切り替えられるようになり、作ったばかりのブランチも送り出せるようになった**。ブランチの一覧は前から読んでいたのに画面に出しておらず、切り替える手立てが無かった。upstream の無いブランチは送り出せなかったので、作れても送れなかった。送り先は upstream があればそれに従い、無いときだけ決める。`origin` があれば `origin`、無くてもリモートが 1 つならそれ、複数あって `origin` が無ければ**断る**（取り違えると、意図しない置き先へ中身が出る）。運用モード（そのまま / ブランチ / PR）という設定は作らない。main を直接触らせない力はアプリでなく置き先の保護設定にあり、設定として持つと**守られていないものが守られているように見える**。
- **送り出したあと、置き先が返してきた案内をブラウザで開けるようになった**。新しいブランチを送ると、置き先が「続きはここで」と PR を作る画面の URL を出力に載せてくる。それを拾って、送り出し完了の知らせの横に出す。URL はこちらで組み立てない（置き先ごとにページの形が違うので、当て推量で作ると開いた先が無い）。API も token も使わない。git の出力をそのままブラウザへ渡すこともせず、`https://` で始まり・ホストがあり・資格情報を含まず・長すぎないものだけを通す。外れたときは案内が出ないだけで、送り出しは成功したまま。案内は押した時点と、次に何か操作した時点で消える（古い URL が別の操作の結果にぶら下がらないため）。

## 0.22.0

### 追加

- **前の版と見比べて、変わったところに印が付くようになった**。直した箇所を赤くして出す慣習があるが、塗るのが人の手なので、塗り忘れた行は「変えていない行」として相手へ渡っていた。過去の版を選ぶと、行 ID で突き合わせて、変わったセル・前の版になかった行と列に印が付く。消えた行はいまの表に置き場がないので、表の下へ中身ごと出す。変わったセル・増えた行・消えた行の数も出る。行 ID が入っていない版とは比べない（比べられないものを「変わっていない」と言わないため）。
- **指摘が本当に直っているかを、表のほうで確かめるようになった**。指摘を出す・対応案を返す・現物へ反映する・確かめて返信する、は別々の手で行われるので、**記録だけが先に進む**。実際に起きたのは、対応案を出しただけの指摘が「反映済み」になり、現物が直らないまま返信が出る形で、渡した相手からは直っていないことしか見えない。書いた本人の申告は根拠にできないので、**その指摘が指している行が、比べている版から実際に変わっているか**を突き合わせ、変わっていなければその場に出す。閉じた指摘には要求しない（対応しないと決めて閉じる指摘は実在するので、要求するとその行が永久に赤いまま残り、赤が消えない表はやがて誰も赤を見なくなる）。比べる版を選んでいない間は何も言わない。新しいシートの雛形に「指摘一覧」を足した。
- **提出様式を決めておいて、その形でコピーできるようになった**。正本は書きやすさで列を並べ、未入力は空のままにする。提出物は先方の様式に従い、列順が決まっていて、空欄を記号で埋めることを求められ、セル内改行を嫌う。いまは提出のたびに人が貼り付け用を組み直していて、手順は毎回同じなのに毎回手でやるので、**正本を直したあと提出物を作り直し忘れる**という形でずれる。ずれは提出物の側にしか出ないため、こちらの手元を見ても見つからない。様式を書いておけば、選んで「コピー」を押すだけで表計算へ貼れる形になる。控え行は出さない。空欄の埋め方も改行の畳み方も**書き出しのときだけ**かかり、正本は書き換えない。
- **共通の観点を、シートへ足せるようになった**。権限・文字数上限・連打・タブ移動順のように、機能が変わっても文面がほぼ同じ観点がある。それを機能ごとに手で書き写しているので、観点を 1 つ足したときに既にあるシートへ行き渡らない。写し漏れは「そのシートに無い」という形でしか現れないので、シートを見ても気づけない。共通の表を指しておけば、そこにあってこのシートに無い観点だけを足す。**既にある行には触らない**（人が入れた結果も、現場に合わせて直した手順も、共通の文面で上書きしない。上書きは一見きれいに揃うが、消えたことが誰にも見えない）。どの列を写すかは毎回書かせる（既定を「同じ名前の列は全部」にすると `結果` 列まで写り、**もう試したことになっている行**が並ぶうえ、見た目は正しい）。共通の表から消えた観点は知らせる。
- **手で印を付けられるようになった**。前の版との突き合わせでは出せない例外がある。前の版がそもそも無い、値は同じで意味が変わった、変えていないセルにも相方として印が要る、の 3 つ。Ctrl / ⌘ + M で選んだ範囲の印を付け外しできる。付けるのと外すのが同じキーなので、外し方だけ忘れるということが起きない（古い印が残ったまま渡るほうが、印が無いより厄介）。比べていない間も出る（比べようがないから手で付けている、という場面があるため）。

## 0.21.0

### 変更

- **いちばん上の行が、窓を動かすためだけの行になった**。この行はアプリが自分で描いているタイトルバーで、掴めるのはボタンが置かれていない余白しかない。保存・書き出し・表示切り替えと押せるものが 9 個並び、書き出しが増えるたびに掴む場所が消えていた。押せるものは 1 つ残らず下の行へ降ろしたので、**上の行はどこを掴んでも窓が動く**。

  - 描けなかった図は、元の文字のまま残す。書きかけの図で本文が消えないようにするため。
  - PDF にもそのまま載る。拡大しても粗くならない形で、図が紙の途中で割れないようにしている。
- **検証シートの列から、別のシートを指せるようになった**。ある列の値が別シートのどの列に載っているはずかをヘッダに 1 行宣言すると、突き合わせが自動で走る。表計算で関数を並べて手で保っていた対応表が要らなくなる。照合は両方向で、指した先に無い値と、どこからも指されていない行の両方が出る。
- **指されている件数を、列として数えられるようになった**。「この観点に紐づく試験が何件あるか」を、シートを開くたびに数え直さなくてよい。
- **選択肢を、別のシートの列から引けるようになった**。選択肢を列の宣言に並べると、増減のたびに使っている全シートのヘッダを直すことになる。一覧が既にシートとして存在するなら、そちらを正本にできる。
  - 参照先を開けないときは、その列を検査しない。選べる値は出ないが、書いてある値はそのまま残る。参照先を開いていないだけで既存の値が一斉に赤くなると、直しようのない赤に本物の違反が埋もれるため。
- **検証グリッドの行番号を右クリックして、行の操作を出せるようになった**（複製 / コピー / クリア / 控えに / 削除）。下の行操作バーはボタンが増え、窓を狭めると畳まれるので、よく使うものを行の上からも出せるようにした。効くのは右クリックした 1 行だけで、開くときに選択をその行へ寄せる。どの行に効くかが押す前に見える。
- **行を最後に変えたのが誰でいつかを、行の上で見られるようになった**（履歴）。検証シートは複数人が同じファイルの別々の行を触るので、NG が付いた行が今日の実施結果なのか半年前のまま残っているのかが表からは分からなかった。行番号に当てると「3 日前 · 誰 · 何をした変更か」が出る。変更履歴を毎回読みにいくので既定は切ってあり、行操作バーのボタンで入れる。履歴の無い行には何も出さない。
- **AI が、ログを全文読み込まずに調べられるようになった**（内蔵の MCP サーバー）。行の検索・行範囲の取り出し・1 行 1 件のログの絞り込み・時間帯別の集計・別々のログを時刻順に混ぜること・取り出した根拠の保存の 6 つ。ログを丸ごと渡すと、調べ始める前に読める量が尽きるうえ、認証情報やメールアドレスが伏せ字を通らずに混ざる。業務文書の読み書きとは別の口にしてある。
- **調査報告書の書式を足した**。ログ調査とネットワーク調査を 1 つの書式で扱う。根拠の欄には文章を書けず、構造化した参照だけを受け付ける。対象ファイルにはハッシュが要る。「そう見えた」が混ざった記録と、後から同じファイルだと確かめられない記録を作らせないため。今のところ AI 側（MCP）から作成・検証できる。

## 0.3.0

### 追加

- **アプリ内蔵の MCP サーバー**。アプリ起動と同時にローカル専用（`127.0.0.1`）の MCP サーバーが立ち上がり、AI クライアントから開いているフォルダの業務文書を読み書きできる。接続先はフォルダを切り替えるたびに追従する。
- **MCP パネル**。右サイドパネルの `MCP` タブに接続先・接続設定のコピー・つなぎ方の手順・ツール実行の操作ログを表示する。表示文言は英語 / 日本語 / 中国語 / 韓国語に対応。
- **接続設定のコピー**。AI クライアントの MCP 設定へそのまま貼れる JSON を 1 押しで写せる。
- **接続先の固定**。ポートと接続トークンを保存し、次に起動しても同じ接続先で立ち上がる。一度貼った設定を書き直さずに使い続けられる。
- **AI の書き込みの自動反映**。MCP 経由で文書が作成 / 更新されると、アプリのファイル一覧とプレビューが自動で追従する。

### 変更

- MCP サーバーが起動できない環境（Node ランタイム未検出など）でも、アプリの他の機能は一切止まらない。パネルに理由だけを表示して動作を続ける。

### 修正

- ステータスバーの MCP 表示が接続状態に関わらず「未接続」のままだった問題を修正。稼働中 / 起動中 / 停止中を色付きで表す。

## 0.2.0

### 追加

- **外部編集のライブ連携**。開いているファイルが他のツールで書き換わると自動で読み込み直す。編集中に外部変更が起きた場合は競合バナーで再読込か自分の変更の維持かを選べる。
- **ヘルプ導線**。上部バーのヘルプから操作マニュアル・バージョン・キーボードショートカット・ライセンスを開ける。
- **UI 多言語対応**（英語 / 日本語 / 中国語 / 韓国語）と、ファイル / 検証グリッド共通の検索。
- **編集体験の改善**。ファイルツリーの右クリックメニュー、TSV グリッドの長文セルの突き抜け表示・undo / redo・オートセーブ、検証グリッドの行の着色・履歴・キー操作、開いていた場所の記憶。

### 修正

- 日本語キーを含む文書が MCP サーバーの検証で必ず invalid になる問題を修正。

## 0.1.0

初回配布リリース。

### 追加

- 6 種の業務文書（invoice / spec / test-spec / db-spec / nosql-db-spec / api-spec）を用途別ビューワーで開き、Markdown を左右 2 画面でライブ編集・PDF 出力する Tauri デスクトップアプリ。
- test-spec の TSV グリッド編集（表計算風の入力ウィジェット + エディターとの round-trip）。
- **アプリ内の自動アップデート**。起動時に新バージョンを自動確認し、ヘルプの「更新を確認」から手動確認もできる。更新は GitHub Releases の署名付き成果物を検証して適用する。

### 配布

- Windows（`.msi` / `.exe`）・macOS（universal `.dmg`）のインストーラを GitHub Releases で配布する。
- コード署名（Windows Authenticode / Apple 公証）は未対応。初回インストール時に発行元不明の警告が出る場合がある。
