# Changelog — @md-business/chrome-extension

この拡張の変更履歴。バージョンは [Semantic Versioning](https://semver.org/lang/ja/) に従う。

0.2.0 と 0.3.0 は付番していない（0.1.1 から 0.4.0 へ飛んでいる）。

## 0.6.0

### 追加

- **請求書以外の書式も開けるようになった**。検証シート・DB 設計書（RDB / NoSQL）・API 仕様書を、請求書や基本設計書と同じようにプレビューして A4 の PDF にできる。書式ごとに別の道具を探さなくてよい。
- **見積書と領収書を、請求書と同じ書式で書けるようになった**。`種別` を書き分けるだけで表題・有効期限・但し書きが切り替わる。
- **書き換えたものをそのままファイルへ保存できるようになった**（Ctrl+S で上書き、Ctrl+Shift+S で名前を付けて保存）。これまでは編集しても、元のファイルへ戻す手段が拡張の中に無かった。

### 変更

- frontmatter を読み取れなかったときの説明を、書いた人向けの言い方に変えた。これまでは英語の技術用語がそのまま出ていた。何行目の何がおかしいのか（字下げ・タブ・項目名の重複・閉じていない引用符など）を示す。

### 修正

- 依存ライブラリを脆弱性修正版へ更新した。

## 0.5.0

### 追加

- **Mermaid の図が描けるようになった**。0.4.0 では拡張の実行制限（MV3 の CSP）に触れるため見送っていたもので、必要な部分だけを取り出して組み直した。

### 変更

- 拡張の名前を「Markdown 業務文書ビューワー」にした。請求書だけでなく基本設計書も開けるようになり、以前の名前が中身と合わなくなっていたため。

### 修正

- 印刷ダイアログを閉じる（キャンセルする）とプレビューが消えてしまう問題を直した。

## 0.4.0

### 追加

- **基本設計書を開けるようになった**。請求書と同じように、プレビューと A4 の PDF 出力ができる。
- **免税事業者の請求書のひな形を、ポップアップから始められるようになった**。ひな形の一覧は種類ごとに分けたので、目的のものを探しやすい。
- 書き方ガイドに、発行元の書き方と免税事業者モードの説明を足した。

### 修正

- プレビューに流し込む前に内容を洗うようにした（DOMPurify）。読み込んだ Markdown に紛れ込んだ実行可能な記述が、そのまま画面で動くことがないようにするため。

## 0.1.1

### 追加

- **ひな形から書き始められるようになった**。ポップアップから選ぶと、その場で編集できる状態で開く。白紙から項目名を思い出す必要がない。
- **左に原稿、右に仕上がりを並べて表示するようにした**。書きながら PDF の見た目を確かめられる。
- **PDF の保存手順を画面で案内するようにした**。ブラウザの印刷ダイアログでヘッダーとフッターを切る手順まで含める。切らないと、日付と URL が紙に載る。
- 日本語のフォント（Noto Sans JP / Noto Serif JP）を同梱した。環境によって字体が変わらない。
- 請求書にテーマカラーとロゴを指定できるようにした。品目名の後ろに `|<数値>` を付けると、その行だけ文字の大きさを変えられる。

### 変更

- 入力の誤りを日本語で、どこが悪いのかが分かる形で出すようにした。
- 拡張が求める権限を `storage` だけに絞った。

### 修正

- PDF が白紙になる／保存名が拡張の名前になってしまう問題を直した。
- 請求書が 1 ページに収まらない問題を直した。

## 0.1.0

### 追加

- Markdown で書いた適格請求書をプレビューし、A4 の PDF として保存できる拡張の最初の版。
