# Changelog — @md-business/chrome-extension

この拡張の変更履歴。バージョンは [Semantic Versioning](https://semver.org/lang/ja/) に従う。

0.2.0 と 0.3.0 は付番していない（0.1.1 から 0.4.0 へ飛んでいる）。

## 0.13.1

### 変更

- **雛形の名前の「英語キー」を「英語フィールド名」に言い換えた**。項目名を英語で書く雛形だと分かるように、「（出力は日本語）」も添えた。

## 0.13.0

### 追加

- **検証シート（`.tsv`）を表の上で直せるようになった**。セルを押すとその場で編集欄が開く。選択肢の列はプルダウン、チェックの列は TRUE / FALSE、日付の列は日付の入力、複数行の列は複数行の欄で開く（確定は Enter、複数行は Ctrl+Enter、取り消しは Esc）。直した結果は左のエディタにも入り、Ctrl+Z で戻せる。
- **行の追加と削除ができるようになった**。表の下の「＋ 行を追加」で末尾に足し、行にカーソルを載せると出る × で消す。通し番号の列は詰め直す。
- **保存すると `.tsv` のまま書き戻す**。開いたときの改行（CRLF / LF）と BOM を保つ。

## 0.12.0

### 追加

- **検証シート（`.tsv`）の用紙を縦・横から選べるようになった**。ツールバーの「横 / 縦」で切り替えると、画面の表示幅と PDF の向きが揃って変わる。既定は横。

## 0.11.0

### 追加

- **検証シート（`.tsv`）を開けるようになった**。1 行目が `#! md-business:test-spec-tsv/v1` のファイルを、ポップアップの選択・ドロップ・ビューワーの差し替えで開くと、読み取り専用の表で出る。結果が OK の行は緑、NG は赤、保留は橙に色が付く。行 ID の列と控えにした行は出さない。
- **検証シートを表のまま PDF に出せるようになった**（A4 横）。文書番号と表題がファイル名になる。
- **雛形の検証シートを TSV 版にした**。一覧の先頭に「検証シート（TSV・推奨）」を置き、Markdown 版は「検証シート（Markdown・Google Sheets 連携用）」として残した。

### 変更

- 請求書の英語キー版の雛形名を「英語キー・標準請求書（出力は日本語）」「英語キー・軽減税率（8%）込み（出力は日本語）」にした。キーが英語なだけで、刷り上がりは日本語のため。

## 0.10.0

### 追加

- **基本設計書に目次を出せるようになった**。frontmatter に `目次表示: true`（`showToc: true` でも可）と書くと、本文の頭に見出し（h1〜h3）の目次が出る。PDF でもリンクとして押せる。
- **文中にマーカーを引けるようになった**。`==読む文==`（または `<mark>`）で背景色が付き、PDF にも刷られる。提出版では印を外して文字だけ残す。
- **下線と文字色を付けられるようになった**。`<u>` と `<span style="color: …">` を本文に書ける。提出版でも残る。

## 0.9.0

### 追加

- **改版の印（CriticMarkup）を基本設計書・調査報告書で読めるようにした**。足したところは下線、消したところは取り消し線で出る。ツールバーの「印あり / 清書」で切り替え、PDF も選んだ形になる。印の色はそのまま刷られる。
- **frontmatter の版が改版履歴の表に無いと、警告で知らせるようにした**。
- **強調にならずに記号のまま刷られる `**` / `__` / `~~` を、行番号付きで知らせるようにした**。`**「重要」**` のように全角の約物に接した強調も強調として描くようにした。
- **見出しと図が、文書の中のリンク先になった**。見出しには GitHub と同じ規則の id が付き、説明が「図 2-1」で始まる図は `#図-2-1` で指せる。PDF でもリンクとして押せる。

## 0.8.0

### 追加

- **基本設計書の区分（社外秘・社内限など）を表紙と各ページの右上に出すようにした**。frontmatter の `classification`（`区分` / `機密区分` でも可）から取る。保存名にも `{区分}` / `{classification}` で入れられる。
- **社内版と提出版を切り替えられるようになった**。本文の `::: 社内`（`::: internal` でも可）から `:::` までは社内版にだけ載り、提出版では落ちる。ツールバーの「社内版 / 提出版」で切り替え、PDF も選んだ版になる。版で中身が変わらない文書（請求書など）ではボタンを出さない。
- **提出版にソースの場所やコミットのハッシュが囲みの外に残っていると、警告で知らせるようにした**。PDF にするのは止めない。

## 0.7.0

### 追加

- **調査報告書を開けるようになった**。`所見` / `対象ファイル` / `使用ツール` を持つ文書を調査報告書として描き、表紙・所見の一覧・本文を A4 の PDF にできる。
- **構成図（` ```zumen `）を描けるようになった**。文書の中に書いた構成をそのまま図にする。デスクトップアプリ・VS Code 拡張と同じ描き方をする。

### 変更

- **グラフ（` ```chart `）とデータ（` ```data `）の囲みに、描けない理由を出すようにした**。どちらも隣のファイルを読む指定で、拡張は開いた 1 枚しか受け取らないため描けない。これまでは囲みが素のまま残り、壊れているのか未対応なのか分からなかった。デスクトップアプリか VS Code 拡張で開けば描ける。
- 文書どうしの相対リンク（`[根拠](evidence/EV-001.md)` など）が、プレビューで消えずに残るようにした。

## 0.6.0

### 追加

- **請求書以外の書式も開けるようになった**。検証シート・DB 設計書（RDB / NoSQL）・API 仕様書を、請求書や基本設計書と同じようにプレビューして A4 の PDF にできる。書式ごとに別の道具を探さなくてよい。
- **見積書と領収書を、請求書と同じ書式で書けるようになった**。`種別` を書き分けるだけで表題・有効期限・但し書きが切り替わる。
- **書き換えたものをそのままファイルへ保存できるようになった**（Ctrl+S で上書き、Ctrl+Shift+S で名前を付けて保存）。これまでは編集しても、元のファイルへ戻す手段が拡張の中に無かった。

### 変更

- frontmatter を読み取れなかったときの説明を、書いた人向けの言い方に変えた。これまでは英語の技術用語がそのまま出ていた。何行目の何がおかしいのか（字下げ・タブ・項目名の重複・閉じていない引用符など）を示す。

### 修正

- 依存ライブラリを脆弱性修正版へ更新した。

## 0.5.0

### 追加

- **Mermaid の図が描けるようになった**。0.4.0 では拡張の実行制限（MV3 の CSP）に触れるため見送っていたもので、必要な部分だけを取り出して組み直した。

### 変更

- 拡張の名前を「Markdown 業務文書ビューワー」にした。請求書だけでなく基本設計書も開けるようになり、以前の名前が中身と合わなくなっていたため。

### 修正

- 印刷ダイアログを閉じる（キャンセルする）とプレビューが消えてしまう問題を直した。

## 0.4.0

### 追加

- **基本設計書を開けるようになった**。請求書と同じように、プレビューと A4 の PDF 出力ができる。
- **免税事業者の請求書のひな形を、ポップアップから始められるようになった**。ひな形の一覧は種類ごとに分けたので、目的のものを探しやすい。
- 書き方ガイドに、発行元の書き方と免税事業者モードの説明を足した。

### 修正

- プレビューに流し込む前に内容を洗うようにした（DOMPurify）。読み込んだ Markdown に紛れ込んだ実行可能な記述が、そのまま画面で動くことがないようにするため。

## 0.1.1

### 追加

- **ひな形から書き始められるようになった**。ポップアップから選ぶと、その場で編集できる状態で開く。白紙から項目名を思い出す必要がない。
- **左に原稿、右に仕上がりを並べて表示するようにした**。書きながら PDF の見た目を確かめられる。
- **PDF の保存手順を画面で案内するようにした**。ブラウザの印刷ダイアログでヘッダーとフッターを切る手順まで含める。切らないと、日付と URL が紙に載る。
- 日本語のフォント（Noto Sans JP / Noto Serif JP）を同梱した。環境によって字体が変わらない。
- 請求書にテーマカラーとロゴを指定できるようにした。品目名の後ろに `|<数値>` を付けると、その行だけ文字の大きさを変えられる。

### 変更

- 入力の誤りを日本語で、どこが悪いのかが分かる形で出すようにした。
- 拡張が求める権限を `storage` だけに絞った。

### 修正

- PDF が白紙になる／保存名が拡張の名前になってしまう問題を直した。
- 請求書が 1 ページに収まらない問題を直した。

## 0.1.0

### 追加

- Markdown で書いた適格請求書をプレビューし、A4 の PDF として保存できる拡張の最初の版。
