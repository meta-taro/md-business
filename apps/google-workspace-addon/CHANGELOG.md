# Changelog — @md-business/google-workspace-addon

このアドオンの変更履歴。バージョンは [Semantic Versioning](https://semver.org/lang/ja/) に従う。

## 0.1.0（未公開）

Google Workspace Marketplace への申請を準備している段階で、まだ配っていない。
以下は `main` に入っている内容。

### 追加

- **検証シートを、スプレッドシートの画面そのままで書けるようになった**。Markdown を書ける人でなくても、いつも使っている表計算の操作で記入できる。列の構成と入力の制限（結果の選択肢など）は Markdown 側の定義から作られる。
- **書いた内容を GitHub へ戻せるようになった**。サイドバーの「GitHub に push」を押すと、Markdown に組み直して commit する。どのリポジトリのどのファイルへ戻すかは、元の Markdown の frontmatter（`repository:`）に書いておく。
  - **自動では送らない**。編集のたびに勝手に commit されると、書きかけの状態が履歴に残り続けるため、押したときだけ送る。
- **手元の `.md` をサイドバーから読み込めるようになった**。GitHub に置いていないファイルも、貼り付けるか選ぶかで表に展開できる。
- サイドバーに、いま何ができる状態なのかを出すようにした。接続に使う個人アクセストークンの有無、送り先のリポジトリ、記入済みの行数が分かる。トークンは伏せ字で表示する。

### 変更

- スプレッドシートを読む権限を、開いているファイルだけに絞った（`.currentonly`）。アカウント内の他のファイルは対象にならない。
- 通信先を `api.github.com` に限る宣言をマニフェストへ入れた。

### 修正

- 表の空欄に `—` / `N/A` / `TBD` が入っていても、空欄として扱うようにした。埋めるための記号が値として書き出されると、後で本当に未記入の行を数えられなくなる。
- Markdown へ書き出すときに frontmatter が消える問題と、日付が `Mon Jun 22 ...` の形で出てしまう問題を直した。
- 表の末尾にある空行を書き出しに含めないようにした。
- 依存ライブラリを脆弱性修正版へ更新した。
