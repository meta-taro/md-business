# 触ってみる一式

**ひととおり開いて、押して、転がして、違和感が無いかを見るための一式**です。
[`../`](../) の例が「書けたものはこう見える」を見せるのに対して、こちらは
**アプリの側を確かめる**ためのもの。中身の正しさより、開いたときの見え方・動きが目的です。

検証シートのように 1 行ずつ判定するものではありません。順番に開いて、
おかしいと思ったところがあれば、それが見つけたかったものです。

## 見るとよいところ

- **開いた直後**。読み込みが引っかからないか、幅が決まる前に文字が跳ねないか
- **切り替え**。文書を続けて開いたときに前の位置が残らないか
- **窓を狭くしたとき**。表が横に転がせるか、列が重ならないか
- **明るい配色と暗い配色**。色分けの意味が変わらないか、色だけに頼っていないか
- **表の 300 行**。下端まで転がして、行の当たり判定と選択範囲の色を見る
- **拡大縮小**。画像と SVG で見え方の差が出るか

## 中身は全部つくりもの

会社名・部屋・登録番号・口座・住所・利用者・ログはすべて架空です。
`T1234567890123` は登録番号として成立しませんし、`example.com` は文書用に取ってあるドメインです。

`08-sheet-large.tsv` / `09-sheet-small.tsv` / `03-test-spec.md` の `結果` 列に入っている
`OK` / `NG` は、**色分けの見え方を確かめるために置いた値**です。誰かが確かめた記録ではありません。
本物の検証シートでは、この列を埋めてよいのは実物を動かして目で見た人だけです。

## 開き方

- **デスクトップアプリ** — このフォルダを開く。`.md` は下書きと見比べ、`.tsv` は表として出る
- **Chrome 拡張** — `.md` を開いて A4 の PDF にする
- **MCP サーバー** — このフォルダを指すと、`.jsonl` を絞ったり `.json` / `.xml` を木で読んだりできる

`.md` は CI で JSON Schema に通しています。壊れた例は壊れた形を教えてしまうためです。
