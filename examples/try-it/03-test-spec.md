# 会議室予約 検証シート（見本）

これは**見本**です。`結果` 列に入っている `OK` / `NG` は、色分けの見え方を確かめるために
置いた値であって、誰かが確かめた記録ではありません。実物のシートでは、`結果` を書くのは
実際にアプリを動かして目で見た人だけです。

Markdown で書く検証シートは、Chrome 拡張で PDF にでき、Google Sheets へも持っていけます。
表として編集したいときは、同じ内容を TSV で書いた [`09-sheet-small.tsv`](./09-sheet-small.tsv) の形になります。

## 検証範囲

- 空き検索（日付・人数・時間帯）
- 予約の作成と取り消し
- 重なりの判定
- 繰り返し予約
- 表示端末への当日一覧

## メモ

- 最長 4 時間の判定が効いていない（NG）
- 取り消せない理由と、繰り返しで飛ばした週の知らせが出ていない（保留 2 件）
- 日付をまたぐところは翌日まで待たないと見られない（未実施）
