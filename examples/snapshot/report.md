# 8 月の様子（見本）

社内の備品貸出管理サイトについて、月の数字をひと月ぶん置いた見本です。
**数字は全部つくりもの**で、書き方（置き場・列・取り直したときの足し方）を見るためのものです。
決まりは [`docs/spec/snapshot-tsv-v1.md`](../../docs/spec/snapshot-tsv-v1.md) にあります。

## 使われ方

```chart
type: line
source: ./analytics/2026-08.tsv
x: 日付
y: セッション, ページビュー
title: セッションとページビュー
```

8/10 の行は値が空です。**空欄を 0 に倒していない**ので、線はそこで途切れます。
「その日は 0 だった」と「その日は分からない」は別のことなので、埋めません。

## サイトの様子

```chart
type: bar
source: ./site-health/2026-08.tsv
x: 日付
y: 見つからないページ
title: 見つからないページの数
```

8/3 から 8/7 にかけて増えているのは、この見本では「消したページへの案内が残っていた」という筋書きです。

## 取り直した行がある

`analytics/2026-08.tsv` の末尾に、8/13 をもう一度取り直した行が足してあります。
先に入っていた行はそのまま残してあり、**取得日時が新しいほうが後から取ったもの**です。
書き換えてしまうと「数字が変わった」こと自体が消えるので、足す形にしています。
図では同じ横位置に点が 2 つ並びます。これは隠さないほうがよいという判断です。
