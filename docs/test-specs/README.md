- **記入者・実施日の列は持たない。** 誰がいつ確認したかは commit に残るので、シート側へ重ねて記録しない。
- **このシートはリリースの関門ではない。** 未実施の行が残ったままリリースしてよい。全行 OK を求めない。
- **`結果` 列を埋めるのは、実物を動かして目で見た人だけ。** ビルド通過やテスト green は実施にあたらないので、AI は書かない。
- **自動テストで合否が出る項目はここへ置かず CI に置く。** ここに残すのは、実物を見ないと判断できないものだけ。行が減るのは設計が進んだ結果であって、劣化ではない。
- **外部からの貢献に本シートの記入は要らない。** PR の受け入れ条件は CI のみ。
