# Snapshot TSV v1 — 図の元になる素の表

`analytics/2026-08.tsv` のように、**取ってきた数字をそのまま置いておく表**の決まり。
業務文書のスキーマ（`invoice/v1` など）とは別で、frontmatter も先頭行の印も持たない **素の TSV** を使う。

本文に置いた図（`chart` の囲み）は、この表を読んで描く。図の書き方そのものは下の「図にする」を見る。

## 検証シートとは別物

| | 検証シート | この表 |
| --- | --- | --- |
| 先頭行 | `#! md-business:test-spec-tsv/v1` | 無し |
| 列の型 | 見出しに書く（`結果:enum(OK\|NG)` など） | 書かない |
| 開き方 | デスクトップアプリの編集できる表 | 図の元。表としては開かない |
| 仕様 | [`test-spec-tsv-v1.md`](./test-spec-tsv-v1.md) | この文書 |

印が無いので、検証シートの規則（列の型・必須・行 ID）は当たらない。**逆に、この表に列の型を書いても効かない。**

## 置き場と名前

```
analytics/2026-08.tsv
site-health/2026-08.tsv
```

- **1 ファイル = 1 か月 = 1 つの出どころ**。`YYYY-MM.tsv` にする。
- 出どころが違う数字を 1 枚に混ぜない（フォルダで分ける）。混ぜると、列が増えるたびに
  どの行がどこから来たのか分からなくなる。
- 図から指すので、文書と同じフォルダの並びに置く。開いているフォルダの外は読めない。

## 行と列

**1 行 = ある時点の数字ひとそろい。**

| 列 | 中身 | 要否 |
| --- | --- | --- |
| `日付` | その数字がいつのものか（`YYYY-MM-DD`） | 必須 |
| 指標の列 | 数字そのもの。列の見出しが指標の名前になる（`セッション` `表示までのミリ秒` …） | 1 つ以上 |
| `取得日時` | **いつ取ったか**（`YYYY-MM-DD HH:MM`） | 必須 |
| `取得元` | **どこから取ったか**。サービス名・画面名・書き出したファイル名など | 必須 |

`取得日時` と `取得元` を必須にしているのは、後から見て「いつの、どこの数字か」が分からない表は
使えないから。同じ日付の行が 2 つ並んだとき、どちらが新しいのかもこの 2 列でしか決まらない。

### 指標を縦に持たない

`指標名` `値` の 2 列にして縦に積む形（いわゆる縦持ち）は**採らない**。図は
`y: セッション, ページビュー` のように**列の見出しで系列を選ぶ**ので、縦持ちにすると
すべての指標が 1 本の系列に混ざる。選び分けるには図の指定側に絞り込みが要り、今は無い。

指標が増えたら列を足す。過去の行にその列が無ければ、その行は空欄のままでよい。

## 覚え書き

`#` で始まる行は読み飛ばされる。表の頭に、何の数字か・どう取ったかを書いておける。

```
# 備品貸出管理サイトの月次。1 行 = 1 日ぶんの数字。
# 分からない日は空欄のまま。0 と混ぜない。
日付	セッション	ページビュー	取得日時	取得元
```

## 空欄は空欄のまま

取れなかった日は**セルを空けたまま**にする。`0` `—` `N/A` で埋めない
（[`docs/data-cell-conventions.md`](../data-cell-conventions.md)）。

「その日は 0 だった」と「その日は分からない」は別のことで、0 に倒すと折れ線が谷を描き、
**実際には無い落ち込みが図になる**。空欄は空欄のまま図へ渡り、線はそこで途切れる。

行ごと落とすのも避ける。落とすと、取れなかったこと自体が記録から消える。

## 取り直したら、書き換えずに足す

同じ期間の数字を取り直したときは、**元の行を残したまま新しい行を足す**。

```
2026-08-13	996	3402	2026-08-15 09:12	example-analytics
2026-08-13	1004	3441	2026-08-20 09:05	example-analytics
```

書き換えてしまうと「数字が変わった」ことが誰にも分からなくなる。どちらが後から取ったものかは
`取得日時` で決まる。図では同じ横位置に点が 2 つ並ぶが、それは隠さない。

## 図にする

同じフォルダの `.md` に、`chart` と書いた囲みを置く。

```
type: line
source: ./analytics/2026-08.tsv
x: 日付
y: セッション, ページビュー
title: セッションとページビュー
```

| 指定 | 中身 |
| --- | --- |
| `type` | `line` / `bar` / `pie` |
| `source` | 表の場所。**開いているフォルダの中**を、その文書から見た相対で書く |
| `x` | 横軸に使う列（円グラフでは内訳の名前） |
| `y` | 値に使う列。読点で区切って複数書ける |
| `title` | 図の題（省略可） |

指した表が無い・列が無い・数として読める値が 1 つも無いときは、**黙って空にせず**理由が図の位置に出る。
書いた指定もそのまま残るので、何を書いたのかは読める。

## 外から取ってくる口はまだ無い

数字を自動で取ってくる部分（アクセス解析やサイト計測との接続）は未実装で、鍵の扱いが要るため
人の作業になる。今この形で置ける数字は、**手で書き出して貼ったもの**になる。
先に置き場と列を決めてあるのは、後から接続を足したときに**表の形を変えずに済ませる**ため。
